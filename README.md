# Data Analysis and Report Writing — Training of Trainers (TOT)

**Data for Health (D4H) Initiative · Kigali, Rwanda · 22–26 March 2027**

This repository contains the complete course package for the five-day Training of Trainers workshop that opens the D4H Data Analysis and Report Writing Project. It is published here as a GitBook so facilitators, country teams, and future cascade trainers can read, search, and download everything from one place.

## Background

The Data for Health Initiative — funded by Bloomberg Philanthropies and implemented with the CDC Foundation — partners with governments to strengthen civil registration, vital statistics, and routine health information systems. The Data Analysis and Report Writing Project exists so that the data governments already collect gets cleaned, analyzed, and written up for decision-makers.

The project's goal is to strengthen the analytical and reporting capacity of government agencies and partners to improve the quality, consistency, and dissemination of public health surveillance and mortality data. This TOT (Phase 1 of 7) builds a cadre of in-country trainers from Bangladesh, Côte d'Ivoire, Rwanda, and Tanzania who will independently sustain and scale these practices.

## How to use this book

- **Facilitators** start with the [Course Overview](docs/overview.md), then work through the [Facilitator Guide](docs/facilitator-guide/front-matter.md) day by day. Every session has objectives, talking points, a minute-by-minute activity plan, and TRAINER TIP boxes on re-teaching each topic back home.
- **Participants** follow the [Participant Workbook](docs/participant-workbook/introduction.md): key points, exercises, and worksheets for each day.
- **Templates** (report, SOP, data dictionary, evaluations, pre/post test) live under [Templates](docs/templates/index.md), each with its original downloadable file.
- **Downloads** — all Excel demo datasets, exercise workbooks, and PowerPoint slide decks are on the [Downloads](docs/downloads.md) page and in `assets/`.

> All datasets in this course are 100% synthetic ("Demoland", 12 fictional districts), created for training. No real records are used anywhere.
